# Security policy

Infra9CORE is maintained by [Unify IT Solutions](https://unify.lk).

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory reporting for `UnifyLK/Infra9CORE`, including affected version,
reproduction steps, impact, and any safe mitigation you identified.

Do not include credentials, production URLs, customer data, or exploit payloads
in a report.

## Supported versions

Only the latest published Infra9CORE minor version receives security fixes. A
security fix is released as a patch unless it requires a generated-project
contract change.

## Security release process

Maintainers validate a fix with the manual release-candidate gate, publish from
an immutable Git tag, document the impact in release notes, and notify reporters
after the fixed version is available.
